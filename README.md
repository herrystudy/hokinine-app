# Hoki Nine Premium — Vercel

Landing page statis, responsive, tanpa framework.

## Deploy ke Vercel
- Upload repository ini ke GitHub.
- Import repository dari Vercel.
- Framework preset: Other / Static.
- Deploy.

## Yang perlu diganti
- Link Google Play pada `index.html`.
- Link tombol Daftar Agen sesuai URL pendaftaran Hoki Nine.
- Jika sudah punya logo SVG/PNG asli, ganti teks `HOKI NINE` di bagian logo.
